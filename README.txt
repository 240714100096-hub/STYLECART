STYLECART - 20 PRODUCT STUDENT E-COMMERCE DEMO

HOW TO OPEN
1. Extract this ZIP file.
2. Open the STYLECART_Ecommerce folder.
3. Double-click index.html, or right-click and choose Google Chrome.

FEATURES
- 20 sample products with product photos, names, prices and ratings.
- Search and category filtering.
- Add to cart, change quantity and remove products.
- Place a demo order and view the saved order ID.
- My Wishlist displays saved products with photos and remove/add-to-cart actions.
- My Orders shows order details and a visual demo tracking timeline.
- Cart, wishlist and orders are saved in browser Local Storage.

IMPORTANT
This is a front-end student demonstration. No real payment is collected and no parcel is shipped. Order tracking is simulated by the Refresh Demo Tracking button. Product images are loaded from Unsplash, so an internet connection is needed for photos.

To reset saved demo data, open the browser developer console and run:
localStorage.clear(); location.reload();

LATEST UPDATE:
- Cart, Wishlist and My Orders open in a centered overlay window from the top navigation.
- Checkout asks for full name, email, 10-digit mobile, delivery address, city, state and 6-digit PIN code.
- Orders save the entered delivery details and show them in My Orders.
- Tracking is simulated for this student project; it does not contact a courier.
- No real email is sent and no real payment is processed.

ORDER-ID TRACKING AND CATEGORY UPDATE:
- Men, Women, Kids and other category chips have a polished style and filter products when clicked.
- My Orders includes a tracking search field. Enter the Order ID to view the saved status, expected delivery date and delivery address.
- Each new order receives an Order ID beginning with SC. Use this same Order ID for tracking.
- This is a front-end student project. Order information is stored locally and is not connected to live courier tracking.

CATEGORY LABEL DISPLAY:
- Men, Women, Kids and the other category names are decorative stylish labels only.
- They are intentionally not clickable and do not filter products.
